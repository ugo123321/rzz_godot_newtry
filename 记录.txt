服务器规范：
1.网页/H5/小程序游戏：接入 Cloudflare 或阿里云/腾讯云的 CDN / WAF。让玩家的流量先经过防护节点，黑客无法知道你真实服务器的 IP
2.操作系统安全配置（防挂马/防入侵）禁用 Root/Administrator 账户直接登录：创建普通用户权限来运行游戏服务端程序。关闭不必要的端口：在云服务器控制台的“安全组”中，仅开放游戏端口（如 8080、3000）和你的 SSH/远程桌面端口。
3.改掉默认端口：将 SSH（默认 22）或远程桌面（默认 3389）修改
4.服务器校验：通关结算
5.匿名注册：在玩家第一次打开游戏时，获取一个设备唯一的“身份证号”（UUID），然后保存在本地；以后每次进游戏，都用这个身份证号去服务器“对暗号”。
[玩家首次打开] -> 发送 device_id  -> [服务器] 创建新账号，生成一个随机密匙(Token)
[玩家后续打开] <- 返回并保存Token <- [服务器] 存入数据库
[后续所有游戏] -> 发送 device_id + Token -> [服务器] 验证两者是否匹配

在负责登录的脚本最上方定义一个测试开关。想在引擎里测试时，true 连服务器，false 纯单机测试
